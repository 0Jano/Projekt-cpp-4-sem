\doxysubsection{Detailed Description}
Imports and exports calendar events using ICS files. 

Provides file-\/based interoperability for calendar events by writing events to i\+Calendar format and importing VEVENT entries into an existing calendar. \doxylink{classEvent}{Event} persistence is delegated to \doxylink{classEventManager}{Event\+Manager}.
