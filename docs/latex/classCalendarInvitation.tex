\doxysubsection{Detailed Description}
Represents an invitation sent to a user to join a shared calendar. 

Stores the invitation identity, related calendar and user IDs, requested role, status, and creation timestamp. Invitation state changes are handled by \doxylink{classInvitationManager}{Invitation\+Manager}.
