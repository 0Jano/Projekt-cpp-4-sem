\doxysubsection{Detailed Description}
Handles user registration and authentication against the SQLite database. 

Provides methods to register users, verify login credentials by email or username, and resolve user identifiers to database IDs. Database access is performed through \doxylink{classDatabaseManager}{Database\+Manager}.
